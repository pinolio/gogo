# gogo?gogo! — 도트 게임 포털

한 번 로그인하면 모든 게임 전적이 쌓이는 넷마블 스타일 게임 모음 사이트입니다.

## 들어 있는 것
| 구분 | 내용 |
|---|---|
| 게임 10종 | 블록 대전 · 블록 쌓기 · 2048 (퍼즐), 스네이크 (아케이드), 바둑 · 오목 · 장기 · 체스 · 장기 알까기 · 숫자 코드 (보드게임) |
| 보드게임 | 컴퓨터와(쉬움·보통·어려움) 또는 둘이서 한 기기로 대국. 컴퓨터를 이기면 포인트 |
| 화면 | 홈 · 대전 · **상점** · 랭킹 · 내 전적 |
| 로그인 | 아이디 + 비밀번호 자유 가입 (이메일 불필요), 가입하면 기본 아바타 자동 생성 |
| 포인트 | 게임마다 승리 +2P / 패배 -1P (최하 0P) — 게임 폴더 `settings.js`에서 조정 |
| 아바타 | 전신 도트 아바타, 8부위 41개 아이템, 상점에서 미리 입어 보고 구입 |
| 전적 | 모든 판의 점수·승패·플레이 시간, 게임별 초기화 |
| 모바일 | 터치 버튼 + 화면 밀기, 가로 모드, 앱 설치(PWA) |

## 포인트 · 레벨 (밸런스 조정 예정)
- 각 게임 폴더의 `settings.js` → `points: { win: 2, lose: -1 }`, 승리 조건 `goal`
- 보유 포인트는 0P 아래로 내려가지 않음 / 서버는 한 판에 ±10P 까지만 인정
- 레벨 = 지금까지 얻은 포인트(누적) 기준: Lv2 4P, Lv3 16P, Lv4 36P … (상점에서 써도 레벨 유지)
- 포인트 랭킹 = 누적 포인트 순

## 상점 · 아바타
- 상단 **상점** 탭 → 부위 선택 → 아이템을 누르면 아래 **미리보기**에 입어 본 모습 ('걸어 보기'로 걷는 모습도 확인)
- 구입하면 바로 착용되고 상단바 · 게임 화면 · 결과 화면 · 대전 대기실 · 상대 판 · 랭킹에 같은 모습으로 표시
- 가격 조정: Supabase Table Editor → `shop_items` (자세한 내용은 `avatar/README.md`)
- 서버 규칙: 포인트가 부족하거나 사지 않은 아이템은 착용 불가

## 블록 대전 (실시간 멀티플레이)
| 항목 | 내용 |
|---|---|
| 인원 | 한 방 최대 6명 (컴퓨터 상대 포함) |
| 방식 | 방장이 **개인전**(모두가 서로 공격) 또는 **팀전**(블루 vs 레드) 선택. 팀전에서는 각자 팀을 고르고, 컴퓨터 팀은 방장이 정함 |
| 입장 | 방 만들기 → 4자리 코드 공유 → 코드 입력 또는 '열린 방' 목록에서 입장 |
| 공격 | 한 번에 3줄 → 상대 모두 1줄, 4줄 → 상대 모두 3줄 (빈칸 위치 무작위). 1~2줄은 공격 없음. 팀전에서는 같은 팀에 공격이 가지 않음 |
| 공정성 | 모든 참가자에게 같은 순서로 블록이 나오고, 30초마다 속도가 오름 |
| 컴퓨터 상대 | 방장이 쉬움·보통·어려움 추가 (혼자 연습용) |
| 점수 | 개인전: (참가자 수 − 순위) × 100 + 보낸 공격 줄 × 10 / 팀전: 승리 팀 200 + 보낸 공격 줄 × 10 |
| 승리 | 개인전은 마지막 1명, 팀전은 상대 팀이 모두 탈락하면 승리 |
| 공격 규칙 바꾸기 | `games/puzzle/battle/settings.js`의 `attack: { 3: 1, 4: 3 }` 숫자만 고치면 됨 (예: `{ 2: 1, 3: 2, 4: 4 }`) |

- **체험 모드:** 같은 브라우저의 다른 탭끼리만 대전됩니다 (테스트용).
- **온라인 모드:** Supabase Realtime으로 서로 다른 기기끼리 대전합니다. 추가 서버나 설정이 필요 없습니다.
  Supabase 대시보드 Realtime 설정에 공개 채널 접근을 막는 옵션이 켜져 있다면 꺼 주세요.
- **무료 한도:** Supabase 무료 요금제 Realtime은 동시 접속 200명·초당 메시지 100건입니다. 상대 화면 갱신을 2초에 1번으로 줄여 두어, 한 반(30명, 6명씩 5개 방)이 동시에 해도 한도 안에 들어가도록 했습니다.
- **업데이트할 때는 `supabase/schema.sql`을 다시 실행**하면 됩니다. 여러 번 실행해도 기존 회원·전적은 지워지지 않습니다.

## 전적 초기화
- **내 전적** 화면의 게임별 [초기화] 버튼, 각 게임 화면의 [내 ○○ 전적 초기화], 대전 로비의 [대전 전적 초기화]에서 할 수 있습니다.
- 누르면 화면 안에서 한 번 더 확인한 뒤 지웁니다. 지운 기록은 되돌릴 수 없습니다.
- 지워지는 것: 그 게임의 최고 점수·승패·플레이 횟수·시간·랭킹 기록 / 그대로인 것: 포인트·레벨·아이템
- 서버 규칙상 **본인 기록만** 지울 수 있습니다.

## 앱으로 쓰기 (휴대폰 + 노트북)
웹사이트 하나로 웹·앱을 함께 운영합니다. 코드를 따로 만들 필요가 없고, 사이트를 고치면 설치된 앱도 자동으로 최신 버전이 됩니다.

| 기기 | 설치 방법 |
|---|---|
| 안드로이드 (크롬) | 상단 **⬇ 앱 설치** 버튼 → 설치 |
| 아이폰·아이패드 (사파리) | 공유 버튼 → **홈 화면에 추가** (버튼을 누르면 안내가 나옵니다) |
| 노트북·PC (크롬·엣지) | 상단 **⬇ 앱 설치** 버튼 또는 주소창 오른쪽 설치 아이콘 |
| 카카오톡 링크로 연 경우 | 크롬·사파리로 다시 연 뒤 설치 |

- **전적 연동:** 같은 아이디로 로그인하면 어느 기기에서든 전적이 하나로 이어집니다 (Supabase 연결 후).
- **오프라인:** 한 번 접속한 뒤에는 인터넷 없이도 게임이 실행됩니다. 오프라인에서 끝낸 판은 기기에 보관했다가 연결되면 자동 저장됩니다.
- **업데이트:** 파일을 고쳐 배포할 때 `sw.js` 맨 위 `VERSION` 숫자를 올려 주세요.
- **조건:** 앱 설치는 https 주소에서만 됩니다. GitHub Pages는 기본으로 https라 그대로 쓰면 됩니다.

### 나중에 앱스토어에도 올리고 싶다면
| 스토어 | 방법 | 비용 | 준비물 |
|---|---|---|---|
| 구글 플레이 | PWABuilder(pwabuilder.com)에 사이트 주소 입력 → 안드로이드 패키지 생성 | 개발자 등록 1회 25달러 | 없음 (윈도우 가능) |
| 애플 앱스토어 | Capacitor로 이 폴더를 감싸 iOS 앱 빌드 | 연 99달러 | 맥(Xcode) 필요 |

지금 만든 PWA가 두 방법의 출발점이므로, 웹 코드는 그대로 재사용됩니다.

## 두 가지 동작 모드
- **체험 모드** (`js/config.js`가 비어 있을 때): 기록이 그 브라우저에만 저장됩니다. 랭킹의 '예시' 플레이어는 화면 확인용입니다.
- **온라인 모드** (Supabase 연결): 어느 기기에서 로그인해도 전적과 랭킹이 공유됩니다.

## 온라인으로 운영하기 (약 20분, 무료)
1. **Supabase 프로젝트 만들기** — https://supabase.com → New project (지역: Northeast Asia (Seoul))
2. **DB 만들기** — SQL Editor → `supabase/schema.sql` 전체 붙여 넣기 → Run
3. **이메일 확인 끄기 (필수)** — Authentication → Sign In / Providers → Email → *Confirm email* 끄기
   (아이디를 내부적으로 `아이디@gogogogo.game` 형태로 바꿔 가입시키므로, 이메일 확인이 켜져 있으면 로그인되지 않습니다.)
4. **키 넣기** — Project Settings → API에서 `Project URL`과 `anon public` 키를 복사해 `js/config.js`에 입력
   (`service_role` 키는 절대 넣지 마세요.)
5. **배포** — 이 폴더를 GitHub 저장소에 올리고 Settings → Pages → Branch: `main` / `/(root)` → Save
   몇 분 뒤 `https://<깃허브아이디>.github.io/<저장소이름>/` 에서 접속됩니다.

## 게임 추가하는 법
`games/README.md`를 보세요. 장르 폴더 안에 게임 폴더를 만들고 `game.js` · `settings.js`를 넣은 뒤, `index.html`과 `sw.js` 목록에 추가하면 됩니다. DB는 고칠 필요가 없습니다.

## 기본 부정행위 차단 (서버)
- 점수가 있는데 플레이 시간이 3초 미만이면 거부
- 초당 3,000점을 넘는 기록 거부
- 3초 안에 연속 저장 거부
- 저장된 기록과 포인트는 수정할 수 없음 (본인 기록을 게임별로 지우는 초기화만 가능)

> 브라우저에서 계산한 점수는 완벽히 막을 수 없습니다. 상품을 거는 대회라면 서버 검증을 더 강화해야 합니다.

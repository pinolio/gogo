| `body/<피부>_<m|f>_<f|s|b>.png` | 몸 그림 (선생님 그림). 피부 18 × 남(m)·여(f) × 앞(f)·옆(s, 오른쪽을 봄)·뒤(b) = 108장 |
| `body/cloth.png` | 상의·하의 색 입히기 마스크 (피부 18 가로 × 남 앞·옆·뒤 / 여 앞·옆·뒤 세로, 칸 72×136, 빨강 = 티 자리 밝기, 초록 = 바지·치마 자리 밝기) |
| `bg/<id>.png` | 배경 그림 9장 (가로 그림 → 아바타 칸에 가운데 맞춰 꽉 채움, 상점 카드는 그림 그대로) |
| `back/<id>.png` | v136 등 장식 10종. 768×116 = 128×116 칸 6개 (앞 아래·앞 위·뒤 아래·뒤 위·옆 아래·옆 위). 한 칸 = 아바타 18×29칸(72×116) + 양옆 7칸(28점). 아래 칸은 몸 뒤, 위 칸은 몸 앞(어깨끈·망토 깃)에 그림. 날개를 입으면 `paint()` 캔버스가 양옆 7칸씩 넓어지고 바깥 여백(음수 margin)으로 자리는 그대로 |

## 그리는 법
```js
GoAvatar.draw(ctx, 아바타, x, y, 배율, { view: 'f'|'s'|'b', walk: 위상, crop: 'bust', scene: true, onBody })
GoAvatar.paint(canvas, 아바타, { scale, view, walk, scene })   // 캔버스 크기까지 맞춤
GoAvatar.bodyCanvas(아바타, view)   // 18×29칸(1칸 = 4점) 몸 그림 캔버스 (게임에서 직접 씀)
```
- 아바타 칸 크기는 예전과 같은 18 × 29 칸 (`GoAvatar.size`) → 게임들의 위치 계산은 그대로
- 그림을 아직 못 받았으면 아무것도 안 그리고, 받으면 `onBody` 로 다시 그림 (paint·paintAll 은 자동)
- 걷기: `walk` = 위상(라디안) → 몸 그림을 다리·팔 조각으로 나눠 부드럽게 (rig · rigSide)
- 새 몸 그림으로 못 그리는 옷·장식은 `bodyNorm()` 이 기본(기본 티·청바지·운동화·짧은 머리)으로 바꿔 그림
- 성별을 아직 안 고른 사람은 남(m) 몸

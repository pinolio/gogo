# avatar — 전신 도트 아바타

`avatar.js` 한 파일에 그리기 규칙과 아이템 목록이 모두 들어 있습니다.

## 구조
- 크기: 16 × 27 칸 도트 (테두리 포함 18 × 29)
- 부위 8가지: 피부 · 헤어 · 모자 · 얼굴 · 상의 · 하의 · 신발 · 등
- 모자·얼굴·등은 비워 둘 수 있고, 나머지는 항상 무언가를 착용합니다.
- 걷기 동작: `frame` 0(서기) · 1 · 3(다리 교대) → 나중에 **아바타로 돌아다니는 게임**에서 그대로 사용
  ```js
  GoAvatar.draw(ctx, 아바타, x, y, 배율, { frame: 1 });   // 걷는 모습
  GoAvatar.legs(frame)                                      // 다리 위치 (충돌 판정 등에 활용)
  ```

## 기본 아바타 (가입하면 자동)
밝은 피부 · 짧은 머리(검정) · 기본 티셔츠 · 청바지 · 기본 운동화 — 모두 무료

## 아이템 가격 (밸런스 조정 예정 · 승리 1판 = 2P 기준)
| 부위 | 무료 | 유료 |
|---|---|---|
| 피부 | 밝은·살구·구릿빛·갈색 | 외계인 20P, 로봇 24P |
| 헤어 | 짧은 머리 2색 | 긴 생머리 6P, 단발 6P, 뾰족 8P, 양갈래 10P, 닭벼슬 12P |
| 모자 | (없음) | 야구 모자 4P, 비니 5P, 토끼 귀 12P, 마법사 18P, 왕관 30P |
| 얼굴 | (없음) | 콧수염 3P, 안경 4P, 마스크 5P, 선글라스 8P |
| 상의 | 기본 티셔츠 | 줄무늬 4P, 교복 6P, 후드티 8P, 유니폼 10P, 정장 15P, 갑옷 25P |
| 하의 | 청바지 | 반바지 3P, 치마 5P, 카고 6P, 갑옷 하의 15P |
| 신발 | 기본 운동화 | 빨간 운동화 3P, 장화 5P, 황금 20P |
| 등 | (없음) | 책가방 6P, 망토 15P, 천사 날개 30P |

## 가격 바꾸는 법
- **온라인(실제 사이트)**: Supabase 대시보드 → Table Editor → `shop_items` 표의 `price`를 고치면 바로 적용 (코드 수정 없음)
- **체험 모드**: `avatar.js`의 `add('부위', 'id', '이름', 가격, ...)`의 가격 숫자

## 새 아이템 추가
1. `avatar.js`에 `add(...)` 한 줄과 그리는 방법(`draw`)을 추가합니다. 기존 아이템을 복사해서 색·칸만 바꾸면 쉽습니다.
2. Supabase SQL Editor에서 한 줄 실행: `insert into shop_items values ('새id', '부위', '이름', 가격);`

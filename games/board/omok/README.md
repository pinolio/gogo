# 오목

## 규칙
- 15줄 판, 흑이 먼저 둡니다.
- 가로·세로·대각선으로 **같은 색 돌 다섯 개 이상**을 먼저 이으면 승리.
- 금수(3·3 금지 등)는 아직 없습니다. (자유 오목)
- **한 수 무르기**: 컴퓨터와 둘 때는 내 수와 컴퓨터 수를 함께 되돌립니다.

## 대국 방식
| 방식 | 내용 | 포인트 |
|---|---|---|
| 컴퓨터와 · 쉬움/보통/어려움 | 내가 항상 먼저 둡니다 | 승리 +2P · 패배 -1P · 무승부 0P |
| 둘이서 한 기기 | 한 화면에서 번갈아 두기 | 없음 (기록만) |

- 랭킹 점수 = 이긴 난이도 (쉬움 100 · 보통 200 · 어려움 300)
- **기권**은 두 번 눌러야 처리됩니다. (실수 방지)

## 컴퓨터 실력
줄 모양 점수(열린 4·3 등)로 공격과 수비를 함께 계산. 쉬움은 실수를 자주 합니다.

## 파일
| 파일 | 내용 |
|---|---|
| `game.js` | 규칙 + 컴퓨터 + 화면 |
| `settings.js` | 포인트 · 랭킹 점수 · 소개 문구 · 배경음악 (**밸런스 조정 예정**) |
| `bgm/` | 배경음악 `bgm.mp3` 넣는 곳 |

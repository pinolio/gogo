# 장기 알까기

## 규칙
- 장기알 16개씩, **초가 먼저** 튕깁니다.
- 내 알을 누른 채 뒤로 당겼다 놓으면 반대 방향으로 날아갑니다. (새총처럼, 많이 당길수록 셈)
- 판 밖으로 떨어진 알은 사라집니다. 내 알이 떨어져도 마찬가지.
- 상대 알을 모두 떨어뜨리면 승리.
- 60번(양쪽 합계)을 튕겨도 안 끝나면 남은 알이 많은 쪽이 승리. 같으면 무승부.

## 대국 방식
| 방식 | 내용 | 포인트 |
|---|---|---|
| 컴퓨터와 · 쉬움/보통/어려움 | 내가 항상 먼저 둡니다 | 승리 +2P · 패배 -1P · 무승부 0P |
| 둘이서 한 기기 | 한 화면에서 번갈아 두기 | 없음 (기록만) |

- 랭킹 점수 = 이긴 난이도 (쉬움 100 · 보통 200 · 어려움 300)
- **기권**은 두 번 눌러야 처리됩니다. (실수 방지)

## 컴퓨터 실력
여러 방향·힘으로 가상 튕기기를 해 보고 결과가 가장 좋은 샷을 고릅니다. 쉬움은 조준이 흔들립니다.

## 파일
| 파일 | 내용 |
|---|---|
| `game.js` | 규칙 + 컴퓨터 + 화면 |
| `settings.js` | 포인트 · 랭킹 점수 · 소개 문구 · 배경음악 (**밸런스 조정 예정**) |
| `bgm/` | 배경음악 `bgm.mp3` 넣는 곳 |

# 체스

## 규칙
- 정식 체스 규칙: **백이 먼저**.
- 캐슬링, 앙파상 포함. 폰이 끝 줄에 가면 **자동으로 퀸**이 됩니다.
- 체크메이트하면 승리, 스테일메이트는 무승부.
- 기물 부족, 50수 규칙, 300수 초과도 무승부.

## 대국 방식
| 방식 | 내용 | 포인트 |
|---|---|---|
| 컴퓨터와 · 쉬움/보통/어려움 | 내가 항상 먼저 둡니다 | 승리 +2P · 패배 -1P · 무승부 0P |
| 둘이서 한 기기 | 한 화면에서 번갈아 두기 | 없음 (기록만) |

- 랭킹 점수 = 이긴 난이도 (쉬움 100 · 보통 200 · 어려움 300)
- **기권**은 두 번 눌러야 처리됩니다. (실수 방지)

## 컴퓨터 실력
알파베타 탐색. 쉬움 1수 · 보통 2수 · 어려움 3수 앞을 봅니다. (규칙 정확성은 perft 테스트로 확인)

## 파일
| 파일 | 내용 |
|---|---|
| `game.js` | 규칙 + 컴퓨터 + 화면 |
| `settings.js` | 포인트 · 랭킹 점수 · 소개 문구 · 배경음악 (**밸런스 조정 예정**) |
| `bgm/` | 배경음악 `bgm.mp3` 넣는 곳 |

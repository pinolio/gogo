# 바둑

## 규칙
- 9줄 바둑판, 흑이 먼저 둡니다. 백에게 **덤 6.5집**.
- 상하좌우로 숨 쉴 곳(활로)이 모두 막힌 돌은 따냅니다.
- **자충수 금지**: 따내는 수가 아니면, 내 돌이 바로 잡히는 자리에는 둘 수 없습니다.
- **패 규칙**: 이전과 똑같은 판 모양이 되는 수는 둘 수 없습니다.
- 두 사람이 연달아 **수 넘기기**를 하면 끝나고, 계가합니다.
- 계가: 판 위의 내 돌 + 내 돌로만 둘러싸인 빈 칸(집). 백은 6.5집을 더합니다.

## 대국 방식
| 방식 | 내용 | 포인트 |
|---|---|---|
| 컴퓨터와 · 쉬움/보통/어려움 | 내가 항상 먼저 둡니다 | 승리 +2P · 패배 -1P · 무승부 0P |
| 둘이서 한 기기 | 한 화면에서 번갈아 두기 | 없음 (기록만) |

- 랭킹 점수 = 이긴 난이도 (쉬움 100 · 보통 200 · 어려움 300)
- **기권**은 두 번 눌러야 처리됩니다. (실수 방지)

## 컴퓨터 실력
몬테카를로 방식 (후보 수를 골라 끝까지 가상으로 둬 보고 많이 이기는 수 선택). 쉬움은 거의 무작위, 어려움은 한 수에 최대 약 2초 생각.

## 파일
| 파일 | 내용 |
|---|---|
| `game.js` | 규칙 + 컴퓨터 + 화면 |
| `settings.js` | 포인트 · 랭킹 점수 · 소개 문구 · 배경음악 (**밸런스 조정 예정**) |
| `bgm/` | 배경음악 `bgm.mp3` 넣는 곳 |

# 장기

## 규칙
- 9×10 판, **초(아래)가 먼저** 둡니다. 상차림은 양쪽 모두 마상상마.
- 궁·사는 궁성 안에서만, 궁성 대각선도 이동 가능.
- 차: 직선 / 포: 다른 기물 하나를 넘어서 이동 (포끼리는 넘거나 잡을 수 없음)
- 마·상: 가는 길 첫 칸이 막히면 못 감 / 졸·병: 앞·옆 한 칸 (궁성 안 대각선 앞 가능)
- 장군을 피할 수 없거나 둘 곳이 없으면 패배.
- 200수가 넘으면 남은 기물 점수로 판정 (한에게 덤 1.5점).

## 대국 방식
| 방식 | 내용 | 포인트 |
|---|---|---|
| 컴퓨터와 · 쉬움/보통/어려움 | 내가 항상 먼저 둡니다 | 승리 +2P · 패배 -1P · 무승부 0P |
| 둘이서 한 기기 | 한 화면에서 번갈아 두기 | 없음 (기록만) |

- 랭킹 점수 = 이긴 난이도 (쉬움 100 · 보통 200 · 어려움 300)
- **기권**은 두 번 눌러야 처리됩니다. (실수 방지)

## 컴퓨터 실력
알파베타 탐색. 쉬움 1수 앞 · 보통 2수 앞 · 어려움 3수 앞을 봅니다.

## 파일
| 파일 | 내용 |
|---|---|
| `game.js` | 규칙 + 컴퓨터 + 화면 |
| `settings.js` | 포인트 · 랭킹 점수 · 소개 문구 · 배경음악 (**밸런스 조정 예정**) |
| `bgm/` | 배경음악 `bgm.mp3` 넣는 곳 |

# 숫자 코드 (다빈치 코드 방식)

## 규칙
- 0~11 숫자 타일이 **검정·흰색 각 12장**, 모두 24장.
- 처음에 4장씩 받고, 내 타일은 **작은 수부터** 놓습니다. 같은 숫자면 검정이 왼쪽.
- 내 차례: 더미에서 검정 또는 흰 타일 1장 뽑기 → 상대의 숨은 타일 하나를 골라 숫자 추리.
  - 맞히면 그 타일이 공개되고, **한 번 더 추리**하거나 **그만하기**(뽑은 타일은 숨긴 채 내 줄에 추가).
  - 틀리면 방금 뽑은 내 타일이 공개됩니다. (더미가 비었으면 내 숨은 타일 하나를 공개)
- 상대 타일을 모두 공개시키면 승리.
- 둘이서 할 때는 차례가 바뀔 때 가림 화면이 나와요. 기기를 넘겨 주세요.
- ※ '다빈치 코드'는 원작 보드게임의 이름이며, 이 게임은 같은 방식의 추리 규칙만 따른 자체 제작 게임입니다.

## 대국 방식
| 방식 | 내용 | 포인트 |
|---|---|---|
| 컴퓨터와 · 쉬움/보통/어려움 | 내가 항상 먼저 둡니다 | 승리 +2P · 패배 -1P · 무승부 0P |
| 둘이서 한 기기 | 한 화면에서 번갈아 두기 | 없음 (기록만) |

- 랭킹 점수 = 이긴 난이도 (쉬움 100 · 보통 200 · 어려움 300)
- **기권**은 두 번 눌러야 처리됩니다. (실수 방지)

## 컴퓨터 실력
공개된 타일과 순서 규칙으로 가능한 숫자를 좁혀서(제약 전파) 확률이 높은 칸을 고릅니다.

## 파일
| 파일 | 내용 |
|---|---|
| `game.js` | 규칙 + 컴퓨터 + 화면 |
| `settings.js` | 포인트 · 랭킹 점수 · 소개 문구 · 배경음악 (**밸런스 조정 예정**) |
| `bgm/` | 배경음악 `bgm.mp3` 넣는 곳 |

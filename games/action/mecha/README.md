# 메카 대전 (mecha) — v25 (로봇 12종 · 사용성 개선)

선생님이 예전에 하던 온라인 로봇 대전 게임(코디넷 '어썰트', 2001~2004)의 방식을 참고해 **새로 만든** 게임입니다.
로봇 이름·모양·무기는 모두 새로 지었고, 그림은 Meshy AI 로 만들었습니다. (원작의 이름·그림은 쓰지 않음)
7~12번 로봇의 기술은 시중 게임(오버워치·리그 오브 레전드·팀 포트리스 2·디아블로·젤다 등)의 **유명한 기술 방식만** 참고했고, 이름·그림·수치는 새로 만들었습니다.

## 방식
| 항목 | 내용 |
|---|---|
| 대결 | **AI 대전**(쉬움·보통·어려움) · **온라인**(방 코드) — 오프라인(한 기기)은 없음 (`settings.js` 의 `noLocal: true`) |
| 인원 | 1:1 · 2:2 (빈자리는 컴퓨터) |
| 시작 | 각자 로봇 12종 중 하나 고르기 — **카드 클릭**, **방향키/WASD 로 옮기고 Enter(또는 Space)**, 숫자 키 `1~9`, `0`=10번, `-`=11번, `=`=12번. 아래쪽에 고른 칸 로봇 설명이 나옴 |
| 이동 | WASD/방향키, 우주라 미끄러지듯 움직임(관성). Shift·Space = 부스터(에너지 20) |
| 무기 | J·K·L 또는 1·2·3 = 근접·원거리·특수. **꾹 누르면 힘 모으기** (0.5초마다 1단계, 최대 3단계: 피해·에너지 ×1.5씩) |
| 조준 | 가장 가까운 상대를 자동으로 조준 (휴대폰도 쉽게). 로봇 앞 화살표가 조준 방향. **은신한 상대는 조준 안 됨** |
| 에너지 | 100, 초당 약 17 차오름. 부스터·무기에 씀 |
| 승리 | 상대 팀 로봇을 모두 격파. 120초가 끝나면 남은 체력(%) 평균이 많은 팀 |
| 포인트 | 컴퓨터·온라인 승리 +2P / 패배 -1P / 무승부 0P |
| 휴대폰 | 로봇 고르기는 카드를 직접 누름 (화면 버튼과 겹쳐 잘못 고르지 않도록 고르기 화면에서는 화면 버튼을 무시) |

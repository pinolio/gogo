# 블록 대전

최대 6명이 블록 쌓기로 겨루는 실시간 대전. 개인전 / 팀전(블루 vs 레드).

## 포인트 규칙 (밸런스 조정 예정)
| 결과 | 조건 | 포인트 |
|---|---|---|
| 승리 | 개인전 **1위** / 팀전 **이긴 팀** | +2P (상대가 모두 컴퓨터면 +1P) |
| 패배 | 승리 조건을 못 채움 | -1P (보유 0P 아래로는 안 내려감) |

바꾸는 곳: 이 폴더의 `settings.js`
- `points: { win: 2, lose: -1 }` → 승리·패배 포인트
- `(순위로 판정)` → 승리 조건

## 공격 규칙
| 한 번에 지운 줄 | 상대에게 |
|---|---|
| 1~2줄 | 없음 |
| 3줄 | 1줄 |
| 4줄 | 3줄 |

`settings.js`의 `attack: { 3: 1, 4: 3 }`에서 바꿀 수 있습니다. 예: 2줄도 공격하려면 `{ 2: 1, 3: 1, 4: 3 }`

## 점수 (랭킹용)
- 개인전: (참가자 수 − 순위) × 100 + 보낸 공격 줄 × 10
- 팀전: 이긴 팀 200 + 보낸 공격 줄 × 10

## 배경음악
이 폴더의 `bgm/` 안에 **`bgm.mp3`** 파일을 넣으면 게임을 시작할 때 자동으로 반복 재생됩니다.
- 파일 이름이나 음량은 `settings.js`의 `bgm: { file: 'bgm/bgm.mp3', volume: 0.5 }`에서 바꿉니다.
- 파일이 없으면 음악 없이 실행되고, 음악 버튼도 보이지 않습니다.
- 플레이어는 게임 화면 오른쪽 **♪ 음악 끄기/켜기** 버튼으로 끌 수 있습니다.

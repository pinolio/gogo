# 2048

같은 숫자를 합쳐 큰 숫자를 만드는 게임.

## 포인트 규칙 (밸런스 조정 예정)
| 결과 | 조건 | 포인트 |
|---|---|---|
| 승리 | **512 타일** 만들기 | +2P |
| 패배 | 승리 조건을 못 채움 | -1P (보유 0P 아래로는 안 내려감) |

바꾸는 곳: 이 폴더의 `settings.js`
- `points: { win: 2, lose: -1 }` → 승리·패배 포인트
- `goal: { tile: 512 }` → 승리 조건

## 배경음악
이 폴더의 `bgm/` 안에 **`bgm.mp3`** 파일을 넣으면 게임을 시작할 때 자동으로 반복 재생됩니다.
- 파일 이름이나 음량은 `settings.js`의 `bgm: { file: 'bgm/bgm.mp3', volume: 0.5 }`에서 바꿉니다.
- 파일이 없으면 음악 없이 실행되고, 음악 버튼도 보이지 않습니다.
- 플레이어는 게임 화면 오른쪽 **♪ 음악 끄기/켜기** 버튼으로 끌 수 있습니다.

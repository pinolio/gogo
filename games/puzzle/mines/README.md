# 지뢰찾기 (mines) — v31

선생님 요청(2026-10-29): "지뢰찾기 하나 만들자. 성공한 시간을 기록으로 남기고. 가로10 세로10으로 총 100칸, 지뢰 20개. 혼자 플레이만"

## 방식
| 항목 | 내용 |
|---|---|
| 판 | 가로 10 × 세로 10 = 100칸, 지뢰 20개 (`settings.js` 의 `cols` · `rows` · `mines`) |
| 목표 | 지뢰가 아닌 80칸을 모두 열면 성공. 지뢰를 열면 실패(모든 지뢰와 틀린 깃발 ✕ 표시) |
| 첫 칸 | 첫 클릭한 칸과 주변 8칸에는 지뢰를 놓지 않음 → 첫 칸에 지는 일이 없고 처음에 넓게 열림 |
| 열기 | 클릭 · 터치. 숫자 0 칸은 주변까지 이어서 자동으로 열림 |
| 깃발 | 오른쪽 클릭 · 길게 누르기(0.38초, 휴대폰 진동) · 게임판 아래 **깃발 모드** 버튼(켜면 누르는 칸에 깃발) |
| 한꺼번에 열기 | 열린 숫자 칸을 누르면(또는 가운데 버튼), 주변 깃발 수가 숫자와 같을 때 나머지 주변 칸을 한꺼번에 열기 |
| 키보드 | 방향키(또는 WASD) 칸 고르기(노란 테두리) · 스페이스/엔터 열기 · F 깃발 · R 새 판 |
| 화면 | 위: 남은 지뢰(20 − 깃발 수) · 시간(0.1초) · 내 최고 기록 / 아래: 안내 줄 / 오른쪽: 랭킹(가장 빠른 시간 TOP 10, 내 기록과 순위) · 규칙 |
| 시간 | 첫 칸을 연 순간부터 잼. 성공하면 0.1초 단위로 기록 |
| 포인트 | 없음 (`points.win` 을 1 등으로 바꾸면 성공할 때마다 그만큼 받음) |

## 기록 (가장 빠른 시간이 1위)
- 서버 랭킹(`leaderboard` 보기)은 **큰 점수가 1위** 이므로 시간을 점수로 바꿔 저장: **점수 = 9000 − (걸린 시간 × 10)** (`settings.js` 의 `toScore`)
  - 예) 45.3초 → 8547 / 2분 → 7800 / 15분이 넘으면 1
  - 서버 검사(점수 ≤ 플레이 초 × 3000, 3초 미만 금지)에 걸리지 않도록 저장할 때 `duration_sec` 은 최소 3초
- 화면에는 `settings.js` 의 **`scoreText(점수)`** 로 다시 시간 글자(예: `45.3초`, `2분 05.3초`)로 보여 줌
  - v31 에서 `js/app.js` 에 공통 기능 추가: 어느 게임이든 settings.js 에 `scoreText` 가 있으면 **랭킹 페이지 · 홈 랭킹 탭 · 게임 카드의 1위/내 최고 · 내 전적 표** 모두 그 글자로 표시 (없으면 예전처럼 숫자)
  - `games/study/common.js` 의 혼자 도전 화면(soloPage)에 `rankLabel`(랭킹 제목 옆 글자) · `fmt`(점수 → 글자) 옵션 추가
- 실패한 판은 저장하지 않음. 손님은 이 기기에만 최고 기록을 남기고, 성공 화면의 '로그인하고 기록 저장'으로 올릴 수 있음
- **칸 수나 지뢰 수를 바꾸면** 난이도가 달라져 예전 기록과 비교가 안 되므로, 관리자 화면에서 이 게임 기록 정리를 생각해 주세요

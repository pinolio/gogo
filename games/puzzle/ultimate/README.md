# Ultimate mode (이벤트) — v27

선생님 요청(2026-10-29): 홈 화면 **맨 위 게임 소개와 게임 목록 사이에 이벤트 칸**을 넣고, **퍼즐512 판으로 2분 동안 칸 안 숫자의 합을 점수**로 랭킹을 만듦. 랭킹은 게임 바로 옆에 보이게.

## 규칙
| 항목 | 내용 |
|---|---|
| 판 | 퍼즐512와 같은 4×4 (같은 숫자를 밀어서 합침, 밀 때마다 2 또는 4가 새로 생김) |
| 시간 | 2분 (`settings.js` 의 `timeLimit: 120`) |
| 점수 | 끝났을 때 **판 위 숫자를 모두 더한 값**. 합쳐도 합은 그대로이고 새 숫자가 생길 때마다 늘어남 → 막히지 않고 많이 밀수록 높음 |
| 끝 | 시간이 끝나거나, **더 움직일 수 없으면 그 자리에서 끝** (퍼즐512처럼 다시 시작하지 않음). Ctrl 다시 시작 없음 |
| 키 | 방향키 · WASD, 휴대폰은 밀기 또는 화면 아래 버튼. 키를 꾹 누른 채 연속 이동은 막음(한 번 누를 때 한 칸) |
| 포인트 | 없음 (`points: { win: 0, lose: 0 }`). 랭킹만 |
| 기록 | `game_id = 'ultimate'` 로 저장 → 서버(Supabase) **SQL 추가 필요 없음** (기존 기록 표·랭킹 뷰 그대로) |

## 화면
- **홈 이벤트 칸** (`js/app.js` `eventHTML`·`loadEventRank`): 왼쪽 소개·[도전하기 ▶]·내 최고, 오른쪽 **랭킹 TOP 5**. `settings.js` 의 `event: true` 인 게임만 나옴
- **게임 화면** `#ultimate` (`game.js`): 가운데 게임판, **바로 오른쪽에 Ultimate 랭킹 TOP 10 + 내 최고·내 순위**, 아래 규칙. 휴대폰은 게임판 아래에 랭킹
- 게임 목록·맨 위 소개(10초마다 바뀌는 칸)·게임별 랭킹 탭에는 넣지 않음 (`hidden: true`)

## 이벤트 끝내기·바꾸기
- 홈 이벤트 칸만 없애기: `settings.js` 의 `event: true` → `false` (게임 화면 `#ultimate` 와 기록은 그대로)
- 시간 바꾸기: `timeLimit` (초). 안내 문구 `eventDesc` 의 "2분" 도 함께 고치기
- 규칙·그림은 퍼즐512(`games/puzzle/p512/game.js`)의 `GoP512.kit`(Engine, drawTiles…)을 그대로 씀. Engine 에 `goal`(목표 숫자), `endOnStuck`(막히면 끝) 옵션 추가

## 시험
- `작업도구\테스트\qa\t_ultimate.js [mobile]`: 홈 이벤트 칸 위치(소개 → 이벤트 → 목록), 게임 목록에 안 나옴, 랭킹이 게임 옆, 2판 플레이(시험은 12초) → 점수 = 판 위 합, 저장·랭킹(게임 옆·홈) 반영, 손님은 [로그인하고 기록 저장], 휴대폰 화면 넘침 없음
